# 1.27.0 — Retouche : les gestes de Photoshop, et un peu plus

- **Alt + clic gauche glissé** : règle la taille (gauche / droite) et la dureté (haut / bas) du pinceau. Un simple Alt + clic reste la pipette. Alt + clic droit glissé marche toujours, comme dans Photoshop.
- **Ctrl + Alt + clic droit glissé** : opacité (gauche / droite) et flux (haut / bas), avec un aperçu de la touche dans la couleur choisie.
- **Maj + Alt + clic droit** : un sélecteur de couleur s'ouvre sous le curseur (carré + bande de teinte, ancienne et nouvelle couleur). Glissez, relâchez ; Échap annule.
- **Opacité exacte au clavier** : 4 puis 5 tapés vite = 45 % ; 0 puis 0 = 0 %. Maj + chiffres pour le flux.
- **Outils à ressort** : maintenez la touche d'un outil (E, J, G…), utilisez-le, relâchez : vous revenez à l'outil d'avant. Un appui bref garde le nouvel outil.
- **Vue d'ensemble** : en plein zoom, maintenez H et cliquez : toute l'image s'affiche avec le cadre de votre vue ; déplacez-le, relâchez, vous y êtes, au même zoom.
- **Calques au clavier** : Alt + [ / ] calque du dessous / dessus, Alt + Maj + [ / ] tout en bas / en haut ; Maj + « + » / Maj + « − » change le mode de fusion (celui de l'outil s'il en a un).
- **Bulle discrète** près du curseur pour [ ], les chiffres et les modes de fusion, au lieu d'une notification.
- Aide (F1) et barre d'état mises à jour.
