# 1.26.1 — Envoyer depuis Kane Explorer

- **Directement dans le Studio IA** : dans Kane Explorer, clic droit sur une image → **Envoyer vers KaneApp** → Img2Img, Inpaint, Extras (agrandir) ou PNG Info. L'image s'ouvre et arrive dans le bon onglet, que KaneApp soit déjà ouvert ou non.
- Demande Kane Explorer 1.24.0 (ou plus récent) pour le menu ; « Ouvrir dans KaneApp » (Retouche) marche comme avant.
